# Data and security policy

This repository is designed for **synthetic, privacy-safe research artifacts only**.

## Never commit

- Production Educational Capstone Portal logs or database exports
- Student or faculty identifiers, email addresses, or credentials
- Grades, scores, review comments, or submission metadata tied to real people
- Capstone reports, source archives, or other student work
- API keys, tokens, `.env` files, or deployment credentials

## Real-data validation

Real-data work must happen in an approved controlled environment after institutional permission, ethics/privacy review, data minimisation, pseudonymisation, retention planning, and access-control review. Publish only aggregated findings and a disclosure-safe data dictionary unless explicit release permission is obtained.

## Reporting a problem

Contact the project team privately rather than opening a public issue containing sensitive data. Revoke any exposed credential immediately and remove it from the repository history before publication.
